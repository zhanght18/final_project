## 3. 反思（AI 工具能力边界）
### 通过本次作业，我对 AI 工具的能力边界有了更深刻的认识：

AI 在代码生成、数据分析和可视化方面确实能够极大提升效率，尤其是重复逻辑或常见函数实现，如统计 OD 热门线路、绘制热力图或计算 MAE/RMSE。AI 能快速提供可执行示例，减少了手动编码时间，并能生成多种可选实现方式（Prompt版、Vibe版）。

### 然而，AI 也存在明显局限：
上下文理解有限：对项目特定的数据结构、字段约束和业务逻辑，AI 输出可能会出错，需要人工审查。
依赖环境和版本：如 Python 3.13 与 PyTorch 兼容问题，AI 生成的代码本身不能保证立即可运行。
可解释性不足：通过对话驱动获取结果时，用户可能难以理解底层实现细节，需要结合 Native 版或 Prompt 版验证。

### 因此，AI 最适合在 辅助编码、生成模板和提供参考方案 上使用，而核心决策、异常处理和最终输出验证仍需人工介入。结合 AI 辅助和手动调试的混合方式，是完成高质量项目的最佳实践。
